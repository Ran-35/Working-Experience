# 布隆过滤器

## 1. 基本概念
布隆过滤器本质上是一个 位数组（Bit Array） 加上一系列 随机映射函数（Hash Functions）。

### 1.1 写入流程 
当你往过滤器中添加一个元素（如 key1）时：  
1️⃣ 多重哈希：程序使用 $k$ 个不同的哈希函数对 key1 进行计算，得到 $k$ 个哈希值。  
2️⃣ 置位：将位数组中这 $k$ 个索引位置的值全部设置为 1。

### 1.2 查询流程 
判断 key2 是否存在时：  
1️⃣ 多重哈希：同样使用那 $k$ 个哈希函数计算出 $k$ 个索引位置。。  
2️⃣ 查看状态：只要有任何一个位置为 0，则 key2 一定不存在。果所有位置全部为 1，则 key2 可能存在。

⚠️注意：key2 可能存在是因为哈希碰撞。可能某个从未出现过的 key3，它计算出的 $k$ 个位置恰好都被其他 Key 刷成了 1。此时，过滤器会无辜地报告 key3 存在。(但绝不会漏判，它说不存在则一定不存在)
