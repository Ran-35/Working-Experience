# Spring Security 和 Shiro

Spring Security 是一个功能强大且高度可定制的身份验证和访问控制框架，它是保护基于 Spring 的应用程序的事实标准。  
简单来说，它的核心任务就两件事：Who are you? (认证) 以及 What can you do? (授权)。

## 1. Spring Security
### 1.1 过滤器链
Spring Security 的底层并不是通过 Servlet 实现的，而是基于 Servlet Filter。当你启动程序时，它会创建一个名为 `springSecurityFilterChain` 的过滤器链。

* **DelegatingFilterProxy**：一个标准的 Servlet 过滤器，它负责将过滤请求委派给 Spring 管理的 Bean。  
* **FilterChainProxy**：包含多个 SecurityFilterChain，根据请求路径决定执行哪一组安全逻辑。  

常见的内置过滤器：  
① **UsernamePasswordAuthenticationFilter**：处理表单登录。  
② **BasicAuthenticationFilter**：处理 HTTP Basic 认证。  
③ **ExceptionTranslationFilter**：处理认证失败或权限不足的异常。  
④ **FilterSecurityInterceptor**：最终决定请求是否能通过。

### 1.2 认证流程
当你输入用户名密码后，内部会发生以下流转：

1️⃣ **AuthenticationToken**：用户提交凭证，系统将其封装成一个 Authentication 对象。  
2️⃣ **AuthenticationManager**：认证管理器（接口），通常由 ProviderManager 实现。  
3️⃣ **AuthenticationProvider**：真正干活的人。比如有专门处理 LDAP 的，有处理数据库的。  
4️⃣ **UserDetailsService**：它是你最常接触的接口。你需要实现它的 loadUserByUsername 方法，去数据库查找用户信息。  
5️⃣ **SecurityContextHolder**：一旦认证成功，用户信息会被存入这里。你可以在代码任何地方通过 SecurityContextHolder.getContext().getAuthentication() 获取当前登录人。

### 1.3 授权流程
认证通过后，系统会检查你是否拥有访问特定资源的 权限 (Privilege) 或 角色 (Role)。

* **RBAC 模型**：基于角色的访问控制。
* **配置方式**：  

① HttpSecurity 配置：在代码中通过 `.requestMatchers("/admin/**").hasRole("ADMIN")` 进行拦截。  

② 注解配置：使用 @PreAuthorize("hasAuthority('write')") 在方法级别控制。


### 1.4 使用案例
#### 1️⃣ 添加依赖
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-security</artifactId>
</dependency>
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>
```
#### 2️⃣ 编写数据库及实体类
```sql
-- 1. 租户表
drop table if exists `sys_tenant`;
CREATE TABLE `sys_tenant`
(
    `id`          BIGINT       NOT NULL COMMENT '主键ID',
    `name`        VARCHAR(100) NOT NULL COMMENT '租户名称',
    `tenant_code` VARCHAR(50)  NOT NULL UNIQUE COMMENT '租户编码/标识',
    `status`      TINYINT  DEFAULT 1 COMMENT '状态: 1有效, 0禁用',
    `expire_time` DATETIME DEFAULT NULL COMMENT '租户服务到期时间',
    `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '租户创建时间',
    `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '租户更新时间',
    PRIMARY KEY (`id`)
) ENGINE = InnoDB
  DEFAULT CHARSET = utf8mb4 COMMENT ='系统表-租户表';

-- 2. 用户表
drop table if exists `sys_user`;
CREATE TABLE `sys_user`
(
    `id`          BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `tenant_id`   BIGINT       NOT NULL COMMENT '所属租户ID',
    `username`    VARCHAR(50)  NOT NULL COMMENT '用户名',
    `password`    VARCHAR(100) NOT NULL COMMENT '加密密码',
    `nickname`    VARCHAR(50)  DEFAULT NULL COMMENT '昵称',
    `real_name`   VARCHAR(50)  DEFAULT NULL COMMENT '真实姓名',
    `email`       VARCHAR(100) DEFAULT NULL COMMENT '邮箱',
    `icon`        VARCHAR(100) DEFAULT NULL COMMENT '头像',
    `mobile`      VARCHAR(100) DEFAULT NULL COMMENT '手机号',
    `enabled`     TINYINT(1)   DEFAULT 1 COMMENT '状态: 1启用, 0禁用',
    `create_time` DATETIME     DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `update_time` DATETIME     DEFAULT CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_tenant_username` (`tenant_id`, `username`),
    KEY `idx_tenant` (`tenant_id`)
) ENGINE = InnoDB
  DEFAULT CHARSET = utf8mb4 COMMENT ='系统表-系统用户表';

-- 3. 角色表
drop table if exists `sys_role`;
CREATE TABLE `sys_role`
(
    `id`          BIGINT      NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `tenant_id`   BIGINT      NOT NULL COMMENT '所属租户ID',
    `code`        VARCHAR(50) NOT NULL COMMENT '角色代码',
    `name`        VARCHAR(50) NOT NULL COMMENT '角色名称',
    `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_tenant_role` (`tenant_id`, `code`)
) ENGINE = InnoDB
  DEFAULT CHARSET = utf8mb4 COMMENT ='系统表-角色表';

-- 4. 菜单权限表
drop table if exists `sys_menu`;
CREATE TABLE `sys_menu`
(
    `id`          BIGINT      NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `parent_id`   BIGINT   DEFAULT 0 COMMENT '父菜单ID',
    `name`        VARCHAR(50) NOT NULL COMMENT '菜单名称',
    `permission`  VARCHAR(100) COMMENT '权限标识',
    `type`        TINYINT  DEFAULT 1 COMMENT '1:菜单, 2:按钮',
    `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`)
) ENGINE = InnoDB
  DEFAULT CHARSET = utf8mb4 COMMENT ='系统表-权限表';

-- 5. 用户角色关联表
drop table if exists `sys_user_role`;
CREATE TABLE `sys_user_role`
(
    `user_id`     BIGINT NOT NULL COMMENT '用户id',
    `role_id`     BIGINT NOT NULL COMMENT '角色id',
    `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`user_id`, `role_id`)
) ENGINE = InnoDB
  DEFAULT CHARSET = utf8mb4 COMMENT ='系统表-用户角色关联表';

-- 6. 系统角色菜单关联表
drop table if exists `sys_role_menu`;
CREATE TABLE `sys_role_menu`
(
    `role_id`     BIGINT NOT NULL COMMENT '角色id',
    `menu_id`     BIGINT NOT NULL COMMENT '菜单id',
    `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`role_id`, `menu_id`)
) ENGINE = InnoDB
  DEFAULT CHARSET = utf8mb4 COMMENT ='系统表-角色菜单关联表';
```
