# 异步编程

异步编程是提升系统并发能力和响应速度的核心技术之一。它允许主线程将耗时的任务（如发送邮件、调用第三方 API、文件处理）交给后台线程池，而主线程立即返回，继续处理其他请求。

## 实现方式

### 1.1 原生线程

最基础的异步方式是手动创建一个新线程（Thread）来处理耗时任务。

#### ①**实现原理**

1️⃣ 主线程启动。  
2️⃣ 创建一个新的子线程。  
3️⃣ 在子线程中执行耗时任务（如 I/O、计算）。  
4️⃣ 主线程立即继续向下执行。  

#### ②**示例**
```java
public class AsyncWithThread {
    public static void main(String[] args) {
        // 1. 创建一个原生线程执行异步任务
        Thread thread1 = new Thread(() -> {
            try {
                // 模拟耗时操作
                System.out.println(Thread.currentThread().getName() + " 正在执行任务1...");
                Thread.sleep(2000);  // 模拟2秒的任务
                System.out.println(Thread.currentThread().getName() + " 任务1完成！");
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        });

        // 2. 启动线程
        thread1.start();

        // 3. 主线程继续执行其他任务
        System.out.println("主线程继续执行其他任务...");

        try {
            // 4. 主线程等待线程1完成
            thread1.join();
        } catch (InterruptedException e) {
            e.printStackTrace();
        }

        // 5. 子线程执行完后，主线程继续执行
        System.out.println("主线程执行完成");
    }
}

```
### 1.2 线程池

它预先创建好一批线程，任务来了就复用，任务走了就归还。

#### ①**使用步骤**

1️⃣ 创建线程池。  
2️⃣ 提交任务。  
3️⃣ 主线程继续执行其他任务。  
4️⃣ 获取异步任务的结果。  
5️⃣ 关闭线程池。  

#### ②**示例**
```java
public class ThreadPoolAsyncDemo {
    public static void main(String[] args) throws InterruptedException, ExecutionException {
        // 1. 创建线程池
        ExecutorService executorService = Executors.newFixedThreadPool(3); // 创建一个固定大小为 3 的线程池

        // 2. 提交异步任务
        Future<Integer> future1 = executorService.submit(() -> {
            // 模拟耗时操作
            System.out.println(Thread.currentThread().getName() + " 正在执行任务1");
            Thread.sleep(2000);  // 模拟耗时操作
            return 100 + 200;    // 返回结果
        });

        Future<Integer> future2 = executorService.submit(() -> {
            // 模拟耗时操作
            System.out.println(Thread.currentThread().getName() + " 正在执行任务2");
            Thread.sleep(3000);  // 模拟耗时操作
            return 400 + 500;    // 返回结果
        });

        // 3. 主线程可以继续执行其他任务
        System.out.println("主线程继续执行其他任务...");

        // 4. 获取异步任务结果（会阻塞，直到结果返回）
        Integer result1 = future1.get();  // 获取任务1的结果
        Integer result2 = future2.get();  // 获取任务2的结果

        // 5. 输出结果
        System.out.println("任务1的结果: " + result1);
        System.out.println("任务2的结果: " + result2);

        // 6. 关闭线程池
        executorService.shutdown();
    }
}
```

⚠️**关键参数**
| **参数**              | **说明**    | **调优建议**    |
| ------------------- | --------- | ------------------ |
| **CorePoolSize**    | 核心线程数     | 对于 **CPU 密集型任务**，设置为 `N+1`（`N` 是 CPU 核数）。对于 **I/O 密集型任务**，设置为 `2N`。以充分利用 CPU 资源并避免线程过多导致的上下文切换开销。 |
| **QueueCapacity**   | 阻塞队列大小    | 根据可用内存和任务量设置，避免队列无限增长导致内存溢出（OOM）。设置合适的队列大小来平衡吞吐量和系统负载。                                            |
| **KeepAliveTime**   | 非核心线程存活时间 | 设置合理的非核心线程空闲时间。对于短任务，可以适当降低，快速释放空闲线程；对于长任务，可以适当增加空闲时间，避免频繁创建和销毁线程。                                |
| **RejectedHandler** | 拒绝策略      | 推荐记录日志或抛出特定异常，以便能及时监控和诊断拒绝的任务。避免使用默认的“丢弃任务”策略，避免任务丢失。                                             |

### 1.3 Spring @Async 

使用 @Async 注解是实现异步编程最简单、最流向的方式。它将开发者从手动创建线程和管理线程池的繁琐工作中解脱出来。

#### ①**基本原理**

基于 Spring AOP (面向切面编程) 的动态代理。

1️⃣ **调用阶段**： 当你在 A 类中调用 B 类的 @Async 方法时，Spring 实际上调用的是 B 类的代理对象。  
2️⃣ **拦截阶段**： 代理对象截获请求，从指定的线程池中获取一个空闲线程。  
3️⃣ **执行阶段**： 将实际的方法调用提交给线程池执行，而代理对象立即给主线程返回一个空结果（或 Future）。  

#### ②**使用步骤**
1️⃣ 开启异步支持(在配置类或启动类上添加 @EnableAsync 注解。)  
2️⃣ 方法上标注`@Async`

⚠️ 无返回值 用`void`；有返回值用`CompletableFuture<T>`(获取异步计算结果)

⚠️ 不要直接使用 Spring 默认的异步执行器！默认情况下，Spring 使用 `SimpleAsyncTaskExecutor`，它为每个请求都新开一个线程，在高并发下会导致 OOM（内存溢出）。  

⚠️ @Async 是对线程池的高度封装，它让业务代码更纯粹。但在使用时，一定要自定义线程池并注意自调用失效的问题。使用自定义线程池，使用时指定名称 `@Async("taskExecutor")`。

```java
// 1.自定义一个线程池
@Configuration
public class ThreadPoolConfig {

    @Bean("taskExecutor")
    public Executor taskExecutor() {
        ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
        executor.setCorePoolSize(10); // 核心线程数
        executor.setMaxPoolSize(20);  // 最大线程数
        executor.setQueueCapacity(200); // 队列容量
        executor.setThreadNamePrefix("Async-Thread-");
        executor.initialize();
        return executor;
    }
}

// 2.主启动类/配置类启用异步
@Configuration
@EnableAsync
public class AsyncConfig {
}

// 3.使用异步
@Service
public class EmailService {

    // 无返回值
    @Async("taskExecutor")
    public void sendEmail(String content) {
        // 模拟耗时操作
        Thread.sleep(2000);
        System.out.println("邮件发送成功：" + content);
    }

    // 有返回值
    @Async("taskExecutor")
    public CompletableFuture<String> findUser(String name) {
    String result = "User: " + name;
    return CompletableFuture.completedFuture(result);
}
}

```
#### ④注意事项
* **同类自调用失效**： 如果在同一个类中，A 方法（无注解）调用 B 方法（有 @Async），异步会失效。
原因： AOP 代理要求调用必须经过代理对象。同类调用是 this 调用，绕过了代理。

* **方法必须是 public**： private 方法无法被代理，因此无法异步。

* **未开启 @EnableAsync**： 忘记在配置类上加开关。

* **循环依赖**： 在某些旧版本 Spring 中，如果在两个 Bean 之间存在异步方法的循环引用，可能会导致启动失败。


### 1.4 使用 `CompletableFuture`

`CompletableFuture` 是 Java 8 引入的异步编程工具，可以简化多线程任务的组合与管理，支持回调、非阻塞执行等功能。它可以与 `Future` 结合使用，但提供了更多的功能，适合复杂的异步任务处理，使得你像写流水线一样编排异步任务。

**核心思想**：CompletableFuture 的精髓在于 CompletionStage。它代表了异步计算的一个阶段。当一个阶段完成时，可以触发下一个阶段。

#### 1.4.1 使用步骤

1️⃣ 创建异步任务，新建一个 `CompletableFuture` 对象。  
2️⃣ 获取结果，使用 `get()` 或者 `run()` 方法。  
3️⃣ 使用 `thenApply()`, `thenAccept()`, `thenCompose()` 等方法对结果进行处理。  

##### ① 创建异步任务

通常我们不手动 new 对象，而是使用静态方法：
```java
// 1. 使用runAsync()不会返回结果
CompletableFuture<Void> future = CompletableFuture.runAsync(() -> {
    System.out.println("Hello World");
}, myExecutor);

// 2. 使用supplyAsync()会返回一个结果
CompletableFuture<String> future = CompletableFuture.supplyAsync(() -> {
    return "Hello World";
}, myExecutor);

```
| **方法**   | **返回值** | **适用场景** | 
| ---------- | ----------- | -------------- |  
| **`runAsync`**    | 无返回值 (`Void`) | 仅执行任务，没有返回结果 |
| **`supplyAsync`** | 有返回值 (`T`)    | 执行任务并返回结果    |

⚠️ 线程池： 默认使用 ForkJoinPool.commonPool()，但在生产环境中建议传入自定义线程池。


##### ② 获取异步任务结果


| **方法**     | **功能**   | **异常抛出**    | **使用场景**      |
| ------------ | ---------- | --------------| ----------------- |
| **`get()`**  | 阻塞当前线程，直到异步任务完成并返回结果。 | 可能抛出 `InterruptedException` 或 `ExecutionException` | 当需要处理任务执行过程中可能出现的异常时使用。                  |
| **`join()`** | 阻塞当前线程，直到异步任务完成并返回结果。 | 不抛出检查型异常，抛出的是 **`CompletionException`** （运行时异常）。   | 当你不需要显式处理异常，或者通过 `join()` 后对异常进行统一处理时使用。 |

```java
public static void main(String[] args) {
        CompletableFuture<Integer> future = CompletableFuture.supplyAsync(() -> {
            System.out.println("Task is running...");
            return 100;
        });

        try {
            // 使用 get() 获取结果，会阻塞直到任务完成
            Integer result = future.get(); // 可能抛出 InterruptedException 或 ExecutionException
            System.out.println("Result from task: " + result);
        } catch (InterruptedException e) {
            System.out.println("Task was interrupted.");
        } catch (ExecutionException e) {
            System.out.println("Exception occurred while executing the task: " + e.getMessage());
        }
    }
```
```java
public class CompletableFutureJoinExample {
    public static void main(String[] args) {
        CompletableFuture<Integer> future = CompletableFuture.supplyAsync(() -> {
            System.out.println("Task is running...");
            return 100;
        });

        try {
            // 使用 join() 获取结果，不会抛出检查型异常
            Integer result = future.join(); // 可能抛出 CompletionException
            System.out.println("Result from task: " + result);
        } catch (Exception e) {
            System.out.println("Exception occurred: " + e.getMessage());
        }
    }
}

```

##### ③ 处理异步任务的结果

可以在 CompletableFuture 完成时继续执行后续的任务。这些方法不会阻塞当前线程，而是通过链式调用继续执行。
| **方法**     | **接收参数** | **是否有返回值** | **说明**                          |
| ------------ | ----------- | --------------- | -------------------------------- |
| **`thenApply`**   | 上一阶段的结果  | 有 | 用于转换结果，类似 `Stream` 的 `map` 方法，将上一阶段的结果转换为新的结果。|
| **`thenAccept`**  | 上一阶段的结果  | 无 | 用于消费结果，处理上一阶段的结果，不返回新的值。使用当前线程（或上一步任务的线程）执行|
| **`thenApplyAsync`**  | 上一阶段的结果  | 无 | 用于消费结果，处理上一阶段的结果，不返回新的值。提交给线程池执行，适合耗时操作|
| **`thenRun`**     | 无             | 无 | 只要上一阶段完成，就执行该操作，不关心上一阶段的结果。|
| **`thenCompose`** | 上一阶段的结果  | 有 | 用于连接两个有依赖关系的异步任务，展开嵌套的 `CompletableFuture`（避免嵌套）。 |

```java
public static void main(String[] args) {
    CompletableFuture<Integer> future = CompletableFuture.supplyAsync(() -> 10);
    
    // 1. thenApply：将 10 乘以 2，得到 20，再加上 3，最终输出 23。
    // 2. thenAccept：只输出23(消费前一个异步任务的结果)，不返回结果
    future.thenApply(result -> result * 2)  // 将结果乘以 2
            .thenApply(result -> result + 3)  // 将结果加 3
            .thenAccept(result -> System.out.println("Final result: " + result)); 

    // 3. 用于在前一个异步任务完成后执行一个操作，且不关心前一个任务的结果
    future.thenRun(() -> System.out.println("Task is completed."));

    // thenCompose() 用于链接两个异步任务，第二个任务的执行依赖于第一个任务的结果。
    future.thenCompose(result -> CompletableFuture.supplyAsync(() -> result * 2))  // 将结果乘以 2
              .thenAccept(result -> System.out.println("Final result: " + result));  // 输出：Final result: 20
}

```

##### ④ 组合两个并行任务

| **方法**               | **接收参数**                   | **是否有返回值** | **说明**                    |
| -------------------- | -------------------------- | ---------- | ------------------------- |
| **`thenCombine`**    | 两个 `CompletableFuture` 的结果 | 有          | 当两个任务都完成时，合并它们的结果并返回新值。   |
| **`thenAcceptBoth`** | 两个 `CompletableFuture` 的结果 | 无          | 当两个任务都完成时，消费它们的结果，但不返回新值。 |
| **`applyToEither`**  | 两个 `CompletableFuture` 的结果 | 有          | 谁先完成，就使用哪个任务的结果。          |

```java
public static void main(String[] args) {
    CompletableFuture<Integer> future1 = CompletableFuture.supplyAsync(() -> {
            try { Thread.sleep(1000); } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
            return 5;
        });
    CompletableFuture<Integer> future2 = CompletableFuture.supplyAsync(() -> 10);

    // 1. thenCombine：等待 future1 和 future2 都完成，合并它们的结果并返回新的值，最终输出 15。
    future1.thenCombine(future2, (result1, result2) -> result1 + result2)  // 合并两个结果
            .thenAccept(result -> System.out.println("Combined result: " + result));  // 输出：Combined result: 15

    // 2. thenAcceptBoth：等待 future1 和 future2 都完成，并消费它们的结果，输出：
    // Consumed result 1: 5
    // Consumed result 2: 10
    future1.thenAcceptBoth(future2, (result1, result2) -> {
        System.out.println("Consumed result 1: " + result1);
        System.out.println("Consumed result 2: " + result2);
    });

    // 在 future1 和 future2 中，谁先完成就使用它的结果。
    future1.applyToEither(future2, result -> "First completed result: " + result)
               .thenAccept(System.out::println);  // 输出：First completed result: 10
}
```


##### ⑤ 多任务并发调度
| **方法**      | **接收参数**          | **触发条件** | **说明**  |
| ------------- | -------------------- | ----------- | ----------|
| **`allOf()`** | 多个 `CompletableFuture` | 所有任务完成   | 等待所有传入的 `CompletableFuture` 完成，常用于“并行执行 -> 全部完成后汇总”。 |
| **`anyOf()`** | 多个 `CompletableFuture` | 任意一个任务完成 | 只要有一个任务完成就触发，适用于“多源查找，谁先完成就用谁”。|

```java
public static void main(String[] args) {
    CompletableFuture<Void> future1 = CompletableFuture.supplyAsync(() -> {
        try { Thread.sleep(1000); } catch (InterruptedException e) { e.printStackTrace(); }
        System.out.println("Task 1 completed");
        return "Task 1 result";
    }).thenAccept(result -> System.out.println(result));

    CompletableFuture<Void> future2 = CompletableFuture.supplyAsync(() -> {
        try { Thread.sleep(2000); } catch (InterruptedException e) { e.printStackTrace(); }
        System.out.println("Task 2 completed");
        return "Task 2 result";
    }).thenAccept(result -> System.out.println(result));

    // 1.allOf()：等待 future1 和 future2 都完成完成后打印 "All tasks completed"。
    // 输出：Task 1 completed
    // 输出：Task 2 completed
    // 输出：Task 1 result
    // 输出：Task 2 result
    // 输出：All tasks completed
    CompletableFuture.allOf(future1, future2).join();
    System.out.println("All tasks completed");

    // 2.anyOf()：只要 future1 或 future2 中的任何一个完成，就会执行 thenAccept() 并打印第一个完成的任务的结果。
    // 输出：First completed task result: Task 2 result
    CompletableFuture<Object> anyOfFuture = CompletableFuture.anyOf(future1, future2);
    anyOfFuture.thenAccept(result -> System.out.println("First completed task result: " + result));

}

```

#### 1.5 异常处理
在异步编程中，try-catch 无法捕获子线程的异常。CompletableFuture 提供了优雅的补救方式。

#### 1.5.1 exceptionally
相当于 catch。当发生异常时，提供一个默认返回值。
```java
CompletableFuture.supplyAsync(() -> 10 / 0)
    .exceptionally(ex -> {
        System.out.println("出错啦: " + ex.getMessage());
        return 0; // 发生异常时的保底值
    })
    .thenAccept(System.out::println);

```

#### 1.5.2 handle
无论是否发生异常都会执行，可以获取结果 res 或异常 ex。
```java
CompletableFuture.supplyAsync(() -> 10 / 0)
    .handle((result, ex) -> {
            if (ex != null) {
                System.out.println("Exception occurred: " + ex.getMessage());
                return -1; // 返回默认值
            } else {
                return result * 2; // 正常结果处理
            }
    })
    .thenAccept(System.out::println);
```

#### 1.5.3 对比
| **方法**      | **接收参数**    | **是否有返回值** | **说明**   |
| ------------- | -------------- | --------------- | --------- |
| **`exceptionally`** | 异常信息（`Throwable`）     | 有        | 当发生异常时，提供一个默认返回值，避免异常导致流程中断。|
| **`handle`**  | 结果（`T`）或异常（`Throwable`） | 有         | 无论是否发生异常，都会执行该操作，可以获取任务的结果或异常并进行处理。 |
