# 常用注解

## 1. `@ConditionalOnProperty`
👉 这是 Spring Boot 中的条件注解，用于控制 Bean 是否加载，取决于配置文件中某个属性的值。

**示例**:
```java
@ConditionalOnProperty(prefix = "websocket", name = "switch", havingValue = "1")
```

| 属性               | 含义                                              |
| ---------------- | ----------------------------------------------- |
| `prefix`         | 配置前缀。例如 `websocket` → 实际匹配 `websocket.switch`   |
| `name`           | 配置的 key 名称。如果有多个可以写数组，如 `{"switch","enable"}`   |
| `havingValue`    | 只有配置值等于这个值时才匹配 Bean，默认是字符串比较                    |
| `matchIfMissing` | 如果配置不存在，是否也匹配。`false` 表示不存在就不加载，`true` 表示不存在也加载 |

## 2. @EventListener
👉  监听事件注解 
**示例**:
```java
@EventListener(ApplicationReadyEvent.class)
```
这个注解用于监听 ApplicationReadyEvent 事件，表示应用启动并准备好时执行某些操作。

## 3. @Order
👉  指定多个 Bean 或组件的执行顺序。可以用于： 配置类、Bean 初始化顺序、过滤器、拦截器等顺序（越小越先执行）

## 4. @TableField(exist = false)
👉  告诉框架，这个字段仅存在于 Java 类中，不要去数据库表的列里找它

## 6. @jackSon

### 6.1 @JsonProperty("name")
👉  使用Jackson 将 JSON 字符串中的字段映射到 Java 对象(Entity)
```java
@Data
@JsonIgnoreProperties(ignoreUnknown = true)
public class IntraMarketPriorGridLimitsEntity {
    
    @JsonProperty("name")   // 将Map中key为name的数据映射到crossSectionName
    private String crossSectionName;

    @JsonProperty("limit")  // 将Map中key为limit的数据映射到stabilityLimit
    private String stabilityLimit;

    private Long id;
    private String date;
    private Date updateDate;
}
```
### 6.2 @JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss", timezone = "GMT+8")
👉  控制日期、时间或数值在 JSON 字符串与 Java 对象之间转换时的“格式”和“时区”。
```java
@Data
@JsonIgnoreProperties(ignoreUnknown = true)
public class IntraMarketPriorGridLimitsEntity {
    
    @JsonProperty("name")   // 将Map中key为name的数据映射到crossSectionName
    @JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss", timezone = "GMT+8")
    private String crossSectionName;

    @JsonProperty("limit")  // 将Map中key为limit的数据映射到stabilityLimit
    @JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss", timezone = "GMT+8")
    private String stabilityLimit;

    private Long id;
    private String date;
    private Date updateDate;
}
```
### 6.3 @JsonIgnoreProperties(ignoreUnknown = true) 
👉  使用Jackson 将 JSON 字符串中的字段映射到 Java 对象(Entity)时，忽略 JSON 中存在但 Java 对象 中不存在的字段
```java
@Data
@JsonIgnoreProperties(ignoreUnknown = true)
public class IntraMarketPriorGridLimitsEntity {
    
    @JsonProperty("name")   // 将Map中key为name的数据映射到crossSectionName
    @JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss", timezone = "GMT+8")
    private String crossSectionName;

    @JsonProperty("limit")  // 将Map中key为limit的数据映射到stabilityLimit
    @JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss", timezone = "GMT+8")
    private String stabilityLimit;

    private Long id;
    private String date;
    private Date updateDate;
}
```



## 7.swagger
| **功能**                 | **Swagger 2 注解**    | **OpenAPI 3 注解（Knife4j 4.0）** | **用途**                                    |
| ---------------------- | ------------------- | ----------------------------- | ----------------------------------------- |
| **描述实体类、DTO、VO**       | `@ApiModel`         | `@Schema`                     | 用于描述实体类、DTO 或 VO，通常与字段注解一起使用              |
| **描述类中的字段（属性）**        | `@ApiModelProperty` | `@Schema`                     | 用于描述实体类中的字段或属性，提供详细信息（如字段描述、示例值等）         |
| **描述 Controller 类**    | `@Api`              | `@Tag`                        | 用于描述一个 Controller 类，通常包含该类的功能信息           |
| **描述 Controller 中的方法** | `@ApiOperation`     | `@Operation`                  | 用于描述 Controller 中的方法，通常用于提供方法的详细描述和返回类型信息 |
| **描述方法参数**             | `@ApiParam`         | `@Parameter`                  | 用于描述 Controller 中方法的参数信息，如参数名称、类型、是否必填等   |


## 8.@ControllerAdvice
👉  Spring 3.2 引入的，底层基于 AOP（面向切面编程）。它会扫描并拦截所有标注了 @RequestMapping（及其子集）的方法。

## 9.注解开发
### 9.1 @interface
声明 注解类 的专用关键字,只负责存储数据。它的“方法”实际上定义的是注解的属性。

### 9.2 @Target({ElementType.METHOD})
定义注解可以标注在代码的什么位置。  
`ElementType.METHOD`：这个注解只能写在 方法 上  
`ElementType.TYPE`：这个注解只能写在 类/接口 上  
`ElementType.FIELD`：这个注解只能写在 成员变量 上  
`ElementType.PARAMETER`：这个注解只能写在 方法参数 上  

### 9.3 @Retention(RetentionPolicy.RUNTIME)
定义了注解的“保质期”。  
`SOURCE`：只留在源码里，编译成 .class 文件就没了（如 @Override）。  
`CLASS`：留在字节码文件里，但 JVM 运行时不加载（默认行为）。  
`RUNTIME`：最常用。JVM 运行时可以通过反射获取到。

### 9.4 @Documented
标记注解。生成 JavaDoc 文档时，该注解的信息会被包含在文档中。
