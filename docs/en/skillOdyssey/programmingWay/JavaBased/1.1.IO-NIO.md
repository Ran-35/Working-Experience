# Input/Output

## 1. Traditional I/O

Data is read and written using byte streams and character streams. This method is based on a stream model, where data is read sequentially, one byte at a time or one character at a time.

### 1.1 Basic Components

#### 1.1.1 Byte Stream

##### ① FileInputStream
   A byte input stream used to read byte data from an input source such as a file or network.

**Constructor**:

```java
FileInputStream fis = new FileInputStream(String path);
FileInputStream fis = new FileInputStream(File file);
```

**Common Methods**:

* `read()`: Reads one byte from the input stream.
* `skip(long n)`: Skips a specified number of bytes.
* `close()`: Closes the stream and releases all associated resources.
* `read(byte[] b)`: Reads bytes from the input stream into a byte array.

```java
public static void main(String[] args) {
    try {
        int data;
        FileInputStream fileInputStream = new FileInputStream("C:\\Users\\ranxi\\Desktop\\test.txt");
        // Read one byte at a time until no more bytes can be read.
        while ((data = fileInputStream.read()) != -1) {
            System.out.print((char) data);
        }
        fileInputStream.close();
    } catch (IOException e) {
        throw new RuntimeException(e);
    }
}
```
##### ② FileOutputStream
A byte output stream is used to write byte data to an output destination (such as a file or network).

**Constructor**:

```java
FileOutputStream fos = new FileOutputStream(String path);
FileOutputStream fos = new FileOutputStream(File file);
FileOutputStream fos = new FileOutputStream(String path, boolean append);    // If append is true, data is appended to the end of the file.
```

**Common Methods**:

* `close()`: Closes the file output stream.
* `write(int b)`: Writes a single byte to the file.
* `write(byte[] b)`: Writes a byte array to the file.
* `write(byte[] b, int off, int len)`: Writes bytes of a specified length from the specified offset in the byte array.

```java
public static void main(String[] args) {
    try {
        FileOutputStream fileOutputStream = new FileOutputStream("C:\\Users\\ranxi\\Desktop\\test.txt");
        fileOutputStream.write("Now is the time for all good men to come.".getBytes());
        fileOutputStream.close();
    } catch (IOException e) {
        throw new RuntimeException(e);
    }
}
```
##### ③ BufferedInputStream
A buffered byte input stream that improves read performance by using a buffer.

**Constructor**:

```java
    BufferedInputStream bis = new BufferedInputStream(FileInputStream fileInputStream);
```
**Common Methods**:

* `read()`: Reads one byte from the buffer.
* `read(byte[] b)`: Reads data from the buffer into a byte array.
* `close()`: Closes the stream and releases associated resources.

```java
public static void main(String[] args) {
    try {
        int data;
        FileInputStream fileInputStream = new FileInputStream("C:\\Users\\ranxi\\Desktop\\test.txt");
        BufferedInputStream bufferedInputStream = new BufferedInputStream(fileInputStream);
        while ((data = bufferedInputStream.read()) != -1) {
            System.out.print((char) data);
        }
    } catch (IOException e) {
        throw new RuntimeException(e);
    }
}
```
##### ④ BufferedOutputStream

Buffered byte output stream.

**Constructor**:

```java
    BufferedOutputStream bos = new BufferedOutputStream(FileOutputStream fileOutputStream);
```

**Common Methods**:

* `write(int b)`: Writes a single byte to the buffer.
* `write(byte[] b)`: Writes a byte array to the buffer.
* `close()`: Flushes the data in the buffer to the target file and closes the stream.
* `write(byte[] b, int off, int len)`: Writes a portion of a byte array to the buffer.

```java
public static void main(String[] args) {
    try {
        FileOutputStream fileOutputStream = new FileOutputStream("C:\\Users\\ranxi\\Desktop\\test.txt", true);
        BufferedOutputStream bufferedOutputStream = new BufferedOutputStream(fileOutputStream);
        bufferedOutputStream.write("\n".getBytes());
        bufferedOutputStream.write("Used for testing file input and output streams".getBytes());
        bufferedOutputStream.close();
        fileOutputStream.close();
    } catch (IOException e) {
        throw new RuntimeException(e);
    }
}
```

#### 1.1.2 Character Streams

##### ① FileReader 

A character input stream used to read character data from an input source (such as a file or network).

**Constructor**:

```java
    FileReader fr = new FileReader(String path);
    FileReader fr = new FileReader(File file);
```

**Common Methods**:

* `close()`: Closes the stream.
* `skip(long n)`: Skips n characters.
* `read()`: Reads one character; returns -1 if the end of the file is reached.
* `read(char[] cbuf)`: Reads characters and stores them in a character array; returns the number of characters actually read.

```java
static void fileReader() {
    try (FileReader fr = new FileReader("C:\\Users\\ranxi\\Desktop\\test.txt")) {
        int data;
        while ((data = fr.read()) != -1) {
            System.out.print((char) data);
        }
    } catch (IOException e) {
        throw new RuntimeException(e);
    }
}
```

##### ② FileWriter 

A character output stream used to write character data to an output destination (such as a file or network).

**Constructor**:

```java
    FileWriter fw = new FileWriter(String path);
    FileWriter fw = new FileWriter(File file);
    FileWriter fw = new FileWriter(String path, boolean append);
```

**Common Methods**:

* `close()`: Closes the stream.
* `write(int c)`: Writes a single character to the file.
* `write(char[] cbuf)`: Writes a character array to the file.
* `write(char[] cbuf, int off, int len)`: Writes a portion of a character array to the file.

```java
static void fileReader() {
    try (FileWriter fw = new FileWriter("C:\\Users\\ranxi\\Desktop\\test.txt", true)) {
        fw.write("\n");
        fw.write("This is a test paragraph");
    } catch (IOException e) {
        throw new RuntimeException(e);
    }
}
```
##### ③ BufferedReader
A buffered character input stream, used to improve the efficiency of reading character data.

**Constructor**:

```java
    BufferedReader bufferedReader = new BufferedReader(FileReader fileReader);
```

**Common Methods**:

* `close()`: Closes the stream.
* `read()`: Reads a single character.
* `read(char[] cbuf)`: Reads characters and stores them in a character array, returning the number of characters actually read.
* `readLine()`: Reads a line of text data (including the newline character). Returns null if the file ends.

```java
static void fileReader() {
    try (FileReader fr = new FileReader("C:\\Users\\ranxi\\Desktop\\test.txt")) {
        BufferedReader bufferedReader = new BufferedReader(fr);
        bufferedReader.lines().forEach(System.out::println);
        bufferedReader.close();
    } catch (IOException e) {
        throw new RuntimeException(e);
    }
}
```
##### ④ BufferedWriter
A buffered character output stream used to improve the efficiency of writing character data.

**Constructor**:

```java
    BufferedWriter bufferedWriter = new BufferedWriter(FileWriter fileWriter);
```
**Common Methods:**

* `write(int c)`: Writes a single character to the buffer.
* `write(char[] cbuf)`: Writes a character array to the buffer.
* `write(char[] cbuf, int off, int len)`: Writes a portion of a character array to the buffer.
* `newLine()`: Inserts a newline character.
* `flush()`: Flushes the buffer, writing the data in the buffer to the file.
* `close()`: Writes the data in the buffer to the file and closes the stream.

```java
static void fileReader() {
    try (FileWriter fw = new FileWriter("C:\\Users\\ranxi\\Desktop\\test.txt", true)) {
        BufferedWriter bufferedWriter = new BufferedWriter(fw);
        bufferedWriter.write("\n");
        bufferedWriter.write("Now, let's start");
        bufferedWriter.close();
    } catch (IOException e) {
        throw new RuntimeException(e);
    }
}
```

## 2. NIO
Introduced in Java 1.4, NIO provides a completely new I/O library, offering more efficient and flexible file operations, network communication, and memory-mapped files compared to traditional I/O streams.

✅**Core**: It allows a single thread to handle multiple connections.

### 2.1 Three Core Components

#### 2.1.1 Buffer

All data operations in NIO rely on the Buffer class. A buffer is a memory area used to store data read from or written to a channel.

**Buffer Types**:

* `ByteBuffer`: Handles byte data.
* `CharBuffer`: Handles character data.
* `IntBuffer`, `FloatBuffer`, `LongBuffer`: Handles the corresponding primitive data types.

**Main Methods**:

* `get()`: Reads data from the buffer.
* `put()`: Writes data to the buffer.
* `clear()`: Clears the buffer, preparing it for rewriting data.
* `remaining()`: Returns the amount of readable data remaining in the buffer.
* `flip()`: Switches the buffer from write mode to read mode, preparing it for reading data.

#### 2.1.2 Channel Used for handling data transmission. Channels function similarly to streams in traditional I/O, but they are bidirectional, allowing both read and write operations.

**Channel Types**:

* `FileChannel`: Used for reading and writing files.
* `SocketChannel`: Used for network I/O over TCP connections.
* `DatagramChannel`: Used for network I/O over UDP connections.
* `ServerSocketChannel`: Used for listening to and receiving TCP connections.

**Main Methods**:

* `close()`: Closes the channel.
* `read(ByteBuffer dst)`: Reads data from the channel into the buffer.
* `write(ByteBuffer src)`: Writes data from the buffer into the channel.

#### 2.1.3 Selector Used to implement non-blocking I/O operations. It allows a single thread to manage multiple channels, detecting which channels are ready for read and write operations, thus achieving efficient network communication or I/O operations.

**Main Methods**:

* `close()`: Closes the Selector.
* `open()`: Opens a Selector.
* `selectNow()`: A non-blocking select method.
* `selectedKeys()`: Returns the set of selected channels.
* `select()`: Blocks and waits until at least one channel is ready for I/O operations.

### 2.2 Usage

💡 NIO no longer reads bytes directly from `InputStream`, but instead operates on `Channel` and `Buffer`, and uses `Selector` to manage multiple connections.

1️⃣ **Open Selector**: Used to listen for events.  
2️⃣ **Open ServerSocketChannel**: Configure it to non-blocking mode.  
3️⃣ **Bind Port and Register**: Register the channel to the Selector and listen for the "Accept Connection" event (OP_ACCEPT).  
4️⃣ **Loop Polling**: Call selector.select() to wait for ready events.  
5️⃣ **Process Events**: Perform logical processing based on the event type (connection, read, write).  

```java
public class NioServer {
    public void start() throws IOException {
        // 1. Create Selector
        Selector selector = Selector.open();

        // 2. Create ServerSocketChannel and configure it to non-blocking
        ServerSocketChannel serverChannel = ServerSocketChannel.open();
        serverChannel.configureBlocking(false);
        serverChannel.bind(new InetSocketAddress(8080));

        // 3. Register the channel with the Selector, listening for accept events
        serverChannel.register(selector, SelectionKey.OP_ACCEPT);

        System.out.println("Server started, listening on port: 8080...");

        while (true) {
            // 4. Wait for events to occur (blocks until an event occurs)
            selector.select();

            // 5. Get all ready events
            Set<SelectionKey> selectedKeys = selector.selectedKeys();
            Iterator<SelectionKey> iterator = selectedKeys.iterator();

            while (iterator.hasNext()) {
                SelectionKey key = iterator.next();
                
                // After processing, remove it to prevent processing the same event again
                iterator.remove();

                if (key.isAcceptable()) {
                    // New client connection
                    handleAccept(serverChannel, selector);
                } else if (key.isReadable()) {
                    // Data available to read
                    handleRead(key);
                }
            }
        }
    }

    private void handleAccept(ServerSocketChannel serverChannel, Selector selector) throws IOException {
        SocketChannel clientChannel = serverChannel.accept();
        clientChannel.configureBlocking(false);
        // Register read event, ready to receive data from the client
        clientChannel.register(selector, SelectionKey.OP_READ);
        System.out.println("New connection received: " + clientChannel.getRemoteAddress());
    }

    private void handleRead(SelectionKey key) throws IOException {
        SocketChannel channel = (SocketChannel) key.channel();
        ByteBuffer buffer = ByteBuffer.allocate(1024);
        int read = channel.read(buffer);
        if (read > 0) {
            buffer.flip(); // Switch to read mode
            System.out.println("Received message: " + new String(buffer.array(), 0, read));
            // Respond to the client
            channel.write(ByteBuffer.wrap("Received".getBytes()));
        } else if (read == -1) {
            // Client closed the connection
            channel.close();
        }
    }

    public static void main(String[] args) throws IOException {
        new NioServer().start();
    }
}
```
