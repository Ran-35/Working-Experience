### Commonly Used Annotations

#### 1. `@ConditionalOnProperty`

👉 This is a conditional annotation in Spring Boot, used to control whether a Bean is loaded, depending on the value of a property in the configuration file.

**Example**:

```java

@ConditionalOnProperty(prefix = "websocket", name = "switch", havingValue = "1")

```

| Property | Meaning |

| ---------------- | ----------------------------------------------- |

| `prefix` | Configuration prefix. For example, `websocket` → actually matches `websocket.switch` |

| `name` | The name of the configured key. If there are multiple, you can write an array, such as `{"switch","enable"}` |

| `havingValue` | Only matches the Bean if the configuration value equals this value; the default is string comparison |

| `matchIfMissing` | Whether to match if the configuration does not exist. `false` means it won't load if it doesn't exist, `true` means it will load even if it doesn't exist.

-------
#### 2. @EventListener

👉 Event Listener Annotation

**Example**:

```java

@EventListener(ApplicationReadyEvent.class)

``` This annotation is used to listen for the ApplicationReadyEvent event, indicating that certain operations will be performed when the application starts and is ready.
